Hand-written design reference for the page editor screen at /website/home, /website/menu-and-footer and /website/pages/{id}, implemented by the admin app in features/website/page-editor/. Sections on the left are in the order visitors see them; the form in the centre is drawn from the section’s fields; the preview on the right shows the draft. From 64rem the three panes sit side by side; below that (and at 400% zoom) they are tabs. The sample content is the public site’s seeded content; every person, place and contact detail is fictional.

A website page is edited with the same screen: the Page banner is fixed first; body blocks (Heading, Paragraph, Bullet list, Photo, Link button) are added, moved and removed. Pages have no draft: Save page changes the page at once, and an unticked “Show this page in the website menu” keeps it out of the menu.

Design-system mock of the Coop admin, built from docs/design-system (light and dark). Forms do not submit; use the state links to review outcomes.
