Responsive

Each frame is a real viewport. The member shell frames include the top bar so the hamburger's aria-expanded and the drawer agree; the open drawer marks the page behind it inert. Shell layout, fixed positioning, the drawer slide and the footer text rules are specimen CSS marked in the frame source (D-5, D-8, D-9).
