Responsive

Each frame is a real viewport: a shell column whose main region scrolls and reserves 4.5rem at the bottom, with the sticky bar as the last child. The hide breakpoints by shell and the equal-share rule at 320 px are specimen CSS marked in the frame source (D-4, D-6). Sign-in pages do not place the component at all (D-5).
