States

The avatar is static: no hover, focus, active or disabled state. The columns show the data states: initials, image loaded, image failed (the src here is invalid, so the browser fires error and the component shows initials; this static page shows the fallback markup), and cleared.

Responsive

The avatar has no media rules; the frames show the sidebar footer, a users table cell, board cards in two and one columns (D-14), the profile image avatar and a conversation row at 320, 360 and 768 px.
