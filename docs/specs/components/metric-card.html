Sizes

One size; the card fills its grid cell and the icon tile is 3rem.

States

The card is static: no hover, focus, active or disabled state exists, and it takes no focus. The only data state is the count itself.

Responsive

The card has no media rules; the page grids do. .metric-cards (components.css) is four columns above 768 px and one column at 768 px and below; the member dashboard's .metric-grid (page CSS, D-9) is one column below 640 px and three at 640 px and above. The 150 px cells show the label wrapping beside a tile that never shrinks (D-10).
