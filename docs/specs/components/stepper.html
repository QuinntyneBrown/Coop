Sizes

States

Each dot is in one of three states; nothing is interactive, so there are no hover, focus, active or disabled states.

AC-13

Responsive

No media rule targets the stepper; the frames show it above the public profile form, inside the admin card and with a French label at 320, 360 and 768 px.

Contrast

The completed dot (accent at 0.5 opacity) is about 2.2:1 and is acceptable only because the label and list order carry the information; it is not listed as a pair.
