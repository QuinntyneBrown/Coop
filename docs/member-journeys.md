# Member Journeys

The member journeys from [`user-journeys.md`](user-journeys.md). Members use
the admin site's member view and see only Dashboard, Maintenance, Documents,
Messages and My profile (ADR 0016, L2-REQ-112). The number is the journey's
rank by value provided, highest first, and matches its video in
[`docs/videos/journeys/`](videos/journeys/).

Signing in, registering, changing a password and signing out are shared with
the office and are listed under "Everyone who signs in" in
[`user-journeys.md`](user-journeys.md). Before signing in, members read the
public site like any visitor: the home page, the website pages and the
published documents.

| # | Journey | Description |
| --- | --- | --- |
| 1 | [Submit a maintenance request](videos/journeys/01-submit-maintenance-request/README.md) | Create a request with details and photos. |
| 2 | [Follow a maintenance request](videos/journeys/02-follow-a-maintenance-request/README.md) | Filter own requests, check status, read and add comments, add a photo. |
| 3 | [Read new notices](videos/journeys/03-read-new-notices/README.md) | Choose how notices reach you; read them on the dashboard and in Documents. |
| 5 | [Message the office](videos/journeys/05-message-the-office/README.md) | Read own conversations and reply. |
| 7 | [View the dashboard](videos/journeys/07-view-the-dashboard/README.md) | See own counts, recent requests, notices and actions. |
| 9 | [Onboard](videos/journeys/09-onboard/README.md) | Welcome, profile, unit selection and confirmation, or skip. |
| 12 | [Manage my profile](videos/journeys/12-manage-my-profile/README.md) | Edit details, set or remove a picture, choose how notices arrive. |
