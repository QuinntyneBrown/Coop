How to use

  1. Link tokens/tokens.css, then assets/fonts.css, then assets/components.css.
  2. Use the class names shown on each component page. They match the implemented apps.
  3. Read colours, spacing, radii and durations through tokens. Never type a raw value.
  4. Engineers can generate platform constants from tokens/tokens.json.
