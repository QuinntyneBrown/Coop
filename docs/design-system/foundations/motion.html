Motion

A 200ms colour transition, a 300ms step dot and a 1s spinner. Reduced motion is handled by the tokens themselves.

Overview

Motion in Coop is minimal and functional. The mocks use one short colour transition on interactive controls, one slightly slower transition on the onboarding step dots, and a looping spinner. Nothing slides, fades in, expands or bounces, and the product defines no easing curve (the browser default ease applies). This page documents only those transitions.

Replayable demos

Select a replay button to run each transition. Each demo moves a dot using the named duration token; the real product applies the same durations to colour, border and background changes.

Spinnerrotation (360 degrees)0.6s for the .spinner ring and 1s for the sync icon (material-icons spin), linear, infinite. --duration-spin is 1sLoading states on lists (ring) and the sync icon

The mocks write the colour transition as the shorthand transition: 0.2s, which animates every property. The system narrows it to the properties listed above.

Accessibility and reduced motion

  • tokens.css sets --duration-base and --duration-slow to 0.01ms and --duration-spin to 2s under @media (prefers-reduced-motion: reduce). Every component that uses the tokens follows automatically; do not write literal durations.
  • The spinner keeps turning, more slowly, because it is the only signal that work is in progress. It is always paired with text or an accessible name.
  • No animation lasts longer than 300ms except the looping spinner, and nothing flashes (WCAG 2.3.1).
  • Do not start a transition on mousedown; state changes run on hover, focus and activation only.

Usage

  • Write transition: background-color var(--duration-base) var(--ease-standard) with the specific properties that change, not all.
  • Use the slow token only for the step indicator. Do not introduce new durations; ask for a token first.
  • The product has no toasts, drawers that animate, accordions or skeleton shimmer, so there are no motion tokens for them.

Drift

  • The mocks turn the ring spinner in 0.6s and the sync icon in 1s. The system uses a single 1s token.
  • The mocks never set an easing function. The system names the browser default as --ease-standard so it can be changed in one place.

Tokens

This page owns every --duration-* and --ease-* token.

TokenValueRole
--duration-baseHover, focus and colour changes (0.2s in the mocks). Reduced motion: 0.01ms.
--duration-slowStep dot changes (0.3s in the mocks). Reduced motion: 0.01ms.
--duration-spinOne spinner rotation (1s). Reduced motion: 2s, still moving.
