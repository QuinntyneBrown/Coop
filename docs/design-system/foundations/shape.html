Shape

Soft corners scaled to the object, two border widths, and four fixed avatar sizes.

Overview

The admin is soft: 12px corners on fields, menus, alerts and sidebar links, 24px on cards, tables and dialogs, 32px on the top corners of a phone sheet, and full pills for buttons, badges, filters, avatars and the search field. Rounded, clearly bounded shapes make each control easy to pick out, and one radius per size keeps screens from looking random. This page also holds the fixed avatar sizes, which the metric-card icon, the empty-state icon and the co-op’s mark reuse.

RadiusUse it for
--radius-xsDocumentation swatches only; no admin component uses it
--radius-smCheckboxes, menu items, tooltips, skeleton lines, the close button in an alert
--radius-mdText fields, selects, menus, alerts, toasts, sidebar links, tab tops, picture thumbnails, the small mark in the sidebar
--radius-lgCards, metric cards, tables, dialogs from 640px, the large logo mark
--radius-xlTop corners of a bottom sheet (dialogs under 640px)
--radius-fullButtons, badges, filter chips and pill tabs, avatars, the search field, pagination links, progress bars, spinners, metric-card icons

Rule of thumb: the bigger the object, the bigger the radius, and a nested shape’s radius is never larger than its container’s. A 44px field gets 12px; a button or a 24px badge is a pill; a card gets 24px so the 12px field inside it never looks rounder than the card.

Border widths

--border-width-hairline
--border-width-thick
  • Hairline (1px) for every edge: cards, fields, dividers, list rows, table cells, the sidebar edge, buttons.
  • Thick (2px) for edges that carry state: the selected tab indicator, the checked checkbox mark, the spinner arc, the featured picture, the hover ring on an avatar button and a hovered link’s underline.
  • The focus ring has its own width, documented in Accessibility.

Avatar sizes

M T NV MF
Avatar sm 32px (the sidebar footer, table rows), md 40px (lists, dialog icons), lg 56px (profile settings, metric-card icons), xl 64px (a profile photo, empty-state icons, the large logo mark). Initials sit on the subtle accent tint; a photo replaces them when there is one.
OWN Housing Co-op
The co-op’s mark at sm (32px, --radius-md, in the sidebar brand) and xl (64px, --radius-lg, on sign-in).

Usage

  • Use the radius token for the component’s size; never mix radii inside one component (the bottom sheet is the one exception: rounded top, square bottom against the screen edge).
  • Never type border-radius: 50% or 9999px; use --radius-full.
  • Never set 1px or 2px borders by hand; use the border-width tokens.
  • Avatars come in the four sizes above only; a user’s initials always sit on the same token colours.

Drift from the implemented admin

The mocks are captures of the running Angular admin, which does not use this system yet. Each difference below is drift: the system value is the one to build to.

  • Radii. The admin uses eight radii with no scale: 8px (fields, tab items, many buttons), 10px (sidebar links), 12px (.btn, .card, metric icons), 14px (dashboard cards and metric cards), 16px, 20px (badges), 24px and 50% (avatars). The system has six steps; cards are 24px, fields 12px, and buttons and badges are pills (--radius-full).
  • Buttons. Admin buttons are rounded rectangles (8 to 12px). The system’s buttons are pills.
  • Avatars. .user-avatar is 36px, between the system’s sm (32px) and md (40px), with a random inline background colour per user. The system uses .avatar in four sizes on --color-accent-subtle.
  • Metric icons. .metric-icon is a 44px rounded square (12px corners). The system’s .metric-card__icon is a 56px circle (--size-avatar-lg, --radius-full).
  • Logo. The sidebar mark is 28px; the system draws it at 32px (--size-avatar-sm) with --radius-md.
  • Borders and focus. All admin borders are 1px, which matches --border-width-hairline; the field focus state is a 3px halo instead of a ring. The system draws focus with --focus-ring-width.
