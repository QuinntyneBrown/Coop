Spacing

A 4px scale from 0 to 48px, one half step for hairlines, and a 24px minimum target size. Inside space belongs to the component; between space belongs to the layout.

WCAG 2.2 AALight appearance onlyTokens: --space-*, --target-min

Overview

Spacing is a 4px scale from --space-0 to --space-12. The mocks already lived close to a 4px rhythm, so the scale keeps their common values (8, 12, 16, 20, 24, 32, 48) and snaps the strays. A step is named by its multiple of 4px, so --space-4 is 16px; the one half step, --space-0-5 (2px), exists for hairline gaps.

Inside versus between

Space does two jobs. Keep them separate so a component can be reused anywhere.

  • Inside a component (padding and the gap between its own parts) uses --space-1 to --space-6. A card is padded --space-5; a compact row --space-3; a badge --space-0-5 by --space-3.
  • Between components (stack gaps, grid gaps, margins) uses --space-4 and up. Related items sit --space-4 apart; groups --space-6; major sections --space-8 to --space-12.
  • Gaps between things belong to the parent (gap), not to margins on the children, so components carry no outside space of their own.
Stack of fields
Padding inside the card is --space-5; the gap between its children is --space-4.

Target size

--target-min is 24px, the WCAG 2.2 AA minimum for a pointer target (2.5.8). It is a floor, not a design size: the mocks' real controls are 32 to 48px tall.

Usage

  • Use a spacing token for every margin, padding and gap. Do not write pixel values.
  • Prefer fewer distinct values on a screen: a view usually needs three or four.
  • Control height is not a spacing token. Components set their own heights, never below --target-min.
  • Reduce nothing at small widths below --space-4 of page padding; phone layouts keep the same tokens and stack instead.

Accessibility

  • Interactive targets are at least --target-min (24px) in both dimensions, or have 24px of clear space around them (WCAG 2.5.8). Primary touch controls in the mocks are 32 to 48px tall.
  • Spacing is in rem, so it grows with the browser text size and survives 200% zoom.
  • Keep at least --space-2 between adjacent small targets so a thumb does not hit the wrong one.
