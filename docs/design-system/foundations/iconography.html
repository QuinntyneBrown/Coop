Foundation · Iconography

Iconography

Thirty plain line icons on a 24-unit grid with a 2px stroke, coloured by the text beside them, each with one meaning and almost always with a word next to it.

Overview

The Coop admin uses 30 line icons, drawn inline as SVG so they inherit the colour of the text beside them and need no icon font or extra download. Each icon means exactly one thing everywhere it appears: the wrench is always maintenance, the bin is always delete. Icons help people find their way, but the word does the work. In the sidebar, the tab bar and on buttons, an icon always sits next to its label, because a picture alone is easy to misread, especially for people who did not grow up with app icons.

Style

  • Grid: a 24 × 24 viewBox with about 2 units of padding inside it.
  • Stroke: 2 units, round caps and joins, no fill (.icon sets fill: none; stroke: currentColor).
  • Colour: currentColor, so an icon is always the colour of the text beside it; alerts and toasts set it from their *-icon tokens, and sidebar links use --color-fg-subtle until the link is current.
  • Markup: <svg class="icon" aria-hidden="true" viewBox="0 0 24 24"> with paths only; no width, height or fill attributes.
  • The co-op logo is not an icon. It is the logo mark (a rounded square with three overlapping circles) and is documented on Logo mark.

Labelling

  • An icon beside visible text is decoration: aria-hidden="true", and the text is the name.
  • An icon-only button has an aria-label with the verb and the object: "Delete Meeting notes.pdf", "Edit mira.fern", "Close". A bare "Delete" in a list of ten rows does not say which row.
  • When a row has visible "Edit" and "Remove" text, the button still gets a fuller aria-label ("Edit About us", "Remove Our garden", "Move Rosalind Achebe up"), as the Pages and Board screens already do.
  • An icon that carries status always sits next to words: the success icon with "“About us” is now on the website."
Word plus icon wherever there is room; icon-only only in dense rows, and always with a full aria-label.

Usage

  • Lead with the icon in buttons, sidebar links and menu items; the label follows.
  • One icon per meaning: the check in a circle is "success" and nothing else; the bin is "delete" or "remove" and nothing else.
  • Copy paths from this sheet; do not redraw them or import icons from another set or font.

Accessibility

  • Meaningful icons reach 3:1 against their background (1.4.11); status icons use the --color-*-icon tokens, which are checked in both themes.
  • Icon-only buttons are 44px square (--target-comfortable); never smaller than 24px (--target-min).
  • In forced-colours mode icons follow currentColor and stay visible; an icon font can be replaced or blocked by the browser, an inline SVG cannot.
  • Each icon means one thing on every screen (3.2.4, consistent identification).

Sources and drift

The icon style is adopted from the Shelfie design system. The set is taken from the icons the admin mocks use: pages/admin-dashboard/default (sidebar, metric cards, quick actions, tab bar), pages/admin-board/default (move up, move down, edit, remove), pages/admin-pages/default (open on the website), pages/admin-users/default (edit and delete row actions), pages/admin-assets/default (upload) and dialogs/admin-asset-detail/default (download).

Drift from the implemented admin

  • The admin draws icons with the Material Icons font (<span class="material-icons">build</span>). The system uses inline stroke SVGs; see the mapping.
  • Most Material icon spans in the mocks have no aria-hidden, so screen readers read the ligature text ("build Maintenance", "admin_panel_settings Roles & Privileges").
  • The document delete button and the user edit and delete buttons are .icon-btn elements with no aria-label; their only name is the ligature text "delete" or "edit". The system names the row: "Delete Meeting notes.pdf".
  • .icon-btn has 4px padding around a 24px glyph (a 32px target). The system's icon button is 44px.
  • The phone tab bar uses home and person for Home and Profile; the system keeps both meanings as Home and Profile.
