Typography

One typeface, Outfit, in six sizes and eight roles. Monospace is for code only, and Material Icons is an icon font, not a text face.

Overview

Coop uses one text family, Outfit, in five weights. The type scale has six sizes and eight roles. Roles bundle weight, size, line height and family into a single font: shorthand, so a component sets font: var(--text-body-sm) and nothing else.

  • Outfit (--font-family-sans) is every piece of interface text. It falls back to the system UI font stack.
  • Monospace (--font-family-mono) is used only for code: token names, class names and snippets in documentation, and the --text-code role.
  • Material Icons (--font-family-icon) is an icon font, not a text face. It renders glyphs from ligature names such as edit; never set running text in it. See Iconography.

Families

Fonts are self-hosted: the Outfit weights 300 to 700 and the Material Icons font are declared in assets/fonts.css.

Measure

Keep running text to about 65 characters per line. In the documentation, paragraphs are capped at 65ch. Product long-form content (notices, by-laws, document viewers) should sit in a container that limits line length rather than stretching across wide screens, and uses --line-height-relaxed.

Usage

  • Set text with a role: font: var(--text-body-sm);. Override only the colour.
  • One h1 per page using --text-h1. Do not skip heading levels to get a size; choose the role separately from the level.
  • Size with rem so the user's browser text size scales the interface. Never set text in px.
  • Do not use Material Icons for text. Icons need a text label or aria-label.

Accessibility

  • Body text is 16px and the smallest text is 14px (--font-size-xs); nothing is set smaller. Because sizes are in rem, text scales with the browser setting; layouts must survive 200% zoom (WCAG 1.4.4) and 400% reflow at 320px (1.4.10).
  • Text spacing must tolerate user overrides: line height 1.5, paragraph spacing 2 times the font size, letter spacing 0.12em, word spacing 0.16em (1.4.12). Do not fix heights on text containers.
  • Text colour contrast is verified on the Color page.
  • Outfit loads with font-display: swap so text is visible before the font arrives.
