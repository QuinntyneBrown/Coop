Spinner

A small turning ring that says "please wait", always with words beside it: "Loading the board list…", "Uploading…". It is how the admin shows that a list or a page is on its way.

WCAG 2.2 AAStatus: stablerole="status"

Overview

Use a spinner when something is loading and nobody can say how long it will take: the Board, Pages and Website lists on first load, the Documents, Maintenance and Messages lists, and a photo uploading in the photo picker.

  • Loading row (.loading): a spinner and a sentence, centred where the content will appear. The page title and its main button (Add director, Add page) stay on screen and keep working.
  • Inline (.inline-status with .spinner--sm): a small spinner beside a short status line, under the control it is about, such as "Uploading…" under Upload a new photo.
  • In a button: a button that is saving shows its own spinner through aria-busy="true"; see button. Do not put a .spinner inside a button.

When the progress is known, use a progress bar. When the layout is known and the wait is short, a skeleton also works. If loading fails, replace the spinner with an alert that offers Try again.

Anatomy

  1. ArcThe top border in --color-accent; turns once every 700ms (--duration-loop ÷ 2).
  2. TrackThe rest of the 2px ring in --color-bg-subtle-hover, so the arc reads against any surface.
  3. TextWhat is loading, in muted body text. It is the message; the ring is decoration.
  4. Loading row.loading: centred flex row, 12px gap, 32px above and below, role="status".

Sizes

Three sizes. Large (40px) for a loading row that stands in for a list or page body. Medium (20px) beside body text. Small (16px) beside small text, such as an inline status.

  • Loaded: the loading row is removed and the list takes its place in one paint. Do not announce "Loaded"; the content speaks for itself.
  • Empty: if the list comes back with nothing in it, show an empty state in place of the spinner.
  • Failed: a danger alert with Try again replaces the spinner, as on Board, Pages and Website.
  • Slow: if loading takes longer than about ten seconds, keep the spinner and add a second sentence, such as "This is taking longer than usual."

Responsive behaviour

  • The loading row is centred in the space the content will fill, at every width.
  • The text wraps under its own start on narrow screens and at 400% zoom; the spinner stays beside the first line and never shrinks (flex: none).
  • Spinner sizes are in rem, so they grow with the person's text size.
  • On phones the bottom tab bar stays visible below a loading row, so people can leave the page while it loads.

Theming

The arc reads --color-accent, the track --color-bg-subtle-hover, and the text --color-fg-muted. All three are theme tokens, so the spinner needs no dark-mode rules. To re-theme one spinner, override --spinner-size for size only; colours come from the theme.

Accessibility

Role and pattern

The loading row or inline status is a role="status" live region (WCAG 4.1.3) whose text says what is loading. The ring itself is aria-hidden="true". If a spinner ever has to stand alone, give it visually hidden text: <span class="visually-hidden">Loading documents</span>. While a region loads, its container may also carry aria-busy="true".

Keyboard

KeyAction
TabNot a stop. The page's real controls (sidebar, Add director) stay reachable while the list loads.

Focus

The spinner never takes focus. When the content arrives, focus stays where it was. After a busy button finishes, focus stays on that button or moves where the action leads (a closed dialog returns focus to its opener).

Labelling

Say what is loading, not just "Loading". Insert the status element with its text already in it, or keep an empty status element on the page and fill it, so screen readers announce it once.

Motion

The ring turns continuously with a linear easing, once per 700ms. It does not flash. Under prefers-reduced-motion the duration token is zeroed and every loop stops after one pass, so the ring rests as a still arc and the words carry the message.

Touch

No targets.

Content

  • "Loading" plus the thing, in the page's own words: "Loading the board list…", "Loading pages…", "Loading the website content…", "Loading documents…", "Loading maintenance requests…", "Loading conversations…".
  • For an action, the verb in progress: "Uploading…", "Saving…".
  • End with the ellipsis character (…), not three full stops.
  • No percentages or time guesses; if you know the percentage, use a progress bar.

Drift from the implemented admin

  • One spinner per screen: Board, Pages and Website each define their own class and keyframes (.board-spinner, .pages-spinner, .website-spinner), and the photo picker reuses .website-spinner at 20px. The system has one .spinner with --sm and --lg.
  • Silent spinners: Documents, Maintenance and Messages show .loading with a spinning Material Icons sync glyph (.spin), with no text and no role="status", so screen readers hear nothing. The system always pairs the ring with words in a status region.
  • Look: implemented rings are 36px with a 4px green-on-grey border, turning once per second, with the text stacked under the ring (display: grid). The system uses 40px (--size-avatar-md) with a 2px violet arc, turns every 700ms, and sets the text beside the ring in one row.
  • Reduced motion: Board, Pages and Website already stop their spinner under reduced motion; the sync glyph keeps turning. The system stops every loop after one pass.
  • Copy: "Loading the board list…", "Loading pages…", "Loading the website content…" and "Uploading…" are kept as they are.
