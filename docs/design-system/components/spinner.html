Spinner

The spinner shows that data is on its way: a centred ring with a hidden label, slowed under reduced motion.

WCAG 2.2 AArole=statusOne size

Overview

The spinner shows that a list or page section is loading. It is a centred ring that rotates, shown while the documents, maintenance and messaging lists fetch data, then replaced by the list or the empty state.

  • .loading centres the spinner in the area being loaded.
  • There is no spinner inside buttons and no progress bar in the mocks; neither is documented.

Anatomy

  1. Ring2rem circle, track in --color-border-default, arc in --color-accent, --border-width-thick stroke.
  2. Hidden label"Loading" in .visually-hidden, read by assistive technology. Required; the mocks have none.

Variants

One variant. The mocks use two implementations: a bordered .spinner ring on the public lists and a rotating sync Material icon (.spin) on the admin lists. The design system uses the ring everywhere.

Loading
The loading block as it appears in a list area.
HTML
<div class="loading" role="status">
  <div class="spinner" aria-hidden="true"></div>
  <span class="visually-hidden">Loading</span>
</div>

Sizes

One size: 2rem (32px), as in the mocks.

States

The spinner has one state: spinning. It is present while loading and removed when data arrives; it never pauses, is not interactive and has no hover or focus state.

Responsive behaviour

No breakpoint rules apply. The ring stays 2rem and centres horizontally in the loading area at every width.

Theming

The product ships one light appearance; there are no theme variants. It reads border and accent tokens only.

Accessibility

Role and pattern

Requirement: the .loading container has role="status" and a visually hidden "Loading" text so the state is announced politely; the ring is aria-hidden. WAI-ARIA has no spinner widget; the status live region is the nearest pattern. The mocks add no role and no text, so loading is silent.

Keyboard

KeyAction
Not applicableThe spinner is not focusable.

Focus

None. Do not move focus to the spinner; keep it where the user was.

Labelling

The hidden text names the activity. Use "Loading" by default; a more specific name ("Loading documents") is allowed when two areas load at once.

Contrast

Spinner arc on page

The arc is a non-text graphic, so 3:1 applies.

Motion

The ring rotates once per --duration-spin (1s, linear, infinite); the mocks use 1s for the icon and 0.6s for the ring. Under prefers-reduced-motion: reduce the token becomes 2s, so the ring turns more slowly but still shows that work is in progress. It is a status indicator, not decoration, so it is not removed.

Touch

Not a target.

Content

  • Hidden text is a single word or short phrase: "Loading".
  • Do not add visible text or percentages; the mocks have none.
  • If loading fails, replace the spinner with an error message in an alert.

Drift

  • Mocks: two implementations. Public lists use .spinner rotating in 0.6s; admin lists use the sync icon with .spin rotating in 1s. Resolved to the ring at --duration-spin (1s).
  • Mocks: padding is 40px or 48px; resolved to 48px.
  • Mocks: no role="status" and no text. Requirement: both, with the ring aria-hidden.
  • Mocks: no reduced-motion rule. The design system slows the ring to 2s under prefers-reduced-motion.
