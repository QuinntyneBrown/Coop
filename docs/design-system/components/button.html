Button

Buttons trigger an action: save, create, delete, sign in. One primary button per view marks the action the view exists for.

WCAG 2.2 AAStatus: stableNative <button>

Overview

Use a button when activating it changes something: it submits a form, opens or confirms a dialog, or deletes. Use a link when it only navigates. The product has five emphasis variants and three sizes.

  • Primary is the one action the view exists for (Sign In, Save, Create).
  • Secondary is the default look, for Cancel and other safe actions.
  • Outline is a lower-emphasis accent action.
  • Danger is destructive and appears in delete confirmations.
  • Sign out (.logout-btn in the mocks) is a danger-toned outline for ending a session.

Anatomy

  1. LabelSentence-case verb phrase and the accessible name. Font --text-label.
  2. ContainerMinimum height --button-height (2.5rem), --radius-md corners, one hairline border, horizontal padding --space-5.
  3. Icon (optional)A .material-icons glyph before the label, separated by --space-2.

Variants

Variants change emphasis, not meaning. Pick by how much attention the action deserves.

Emphasis from highest to lowest; danger is reserved for destructive actions.
HTML
<button class="btn btn-primary" type="button">Primary</button>
<button class="btn btn-secondary" type="button">Secondary</button>
<button class="btn btn-outline" type="button">Outline</button>
<button class="btn btn-danger" type="button">Danger</button>
<button class="btn btn-sign-out" type="button">Sign out</button>

Width and button rows

.btn-full (also .btn-block) fills its container; the sign-in and register submits use it.
.btn-row right-aligns a group with --space-3 gaps; .modal-actions is the dialog equivalent and gives each button an equal share.
HTML
<div class="btn-row">
  <button class="btn btn-secondary" type="button">Cancel</button>
  <button class="btn btn-primary" type="button">Save</button>
</div>

Sizes

Medium is the default. Small appears in page toolbars (New conversation); large in landing calls to action.

Heights come from --button-height; small pads --space-4, large pads --space-8 and uses --font-size-md.
HTML
<button class="btn btn-primary btn-sm" type="button">Small</button>
<button class="btn btn-primary" type="button">Medium</button>
<button class="btn btn-primary btn-lg" type="button">Large</button>

States

Hover, focus and active are forced here with data-state so they can be reviewed without a mouse; real pages use :hover, :focus-visible, :active and :disabled.

Busy (submitting)

The implemented busy button is the native disabled attribute plus a changed label ("Signing in...", "Creating account..."). There is no spinner and no aria-busy in the mocks; a spinner button is not implemented.

Disabled primary with the busy label, as in the login and register submitting states.
HTML
<button class="btn btn-primary btn-full" type="submit" disabled>Signing in...</button>

Responsive behaviour

The mocks define no @media rule for this component, so it does not change at the 640, 768 or 1024 breakpoints. Buttons keep their height at every width. The sign-in and register submits use .btn-full so they span the form on phones, and .modal-actions keeps dialog buttons on one row with equal shares.

Theming

The product ships one light appearance, so this component has no theme variants. It reads semantic tokens only; see the tokens section.

Accessibility

Role and pattern

Native <button type="button">, or type="submit" inside a form: the WAI-ARIA Button pattern with no extra role.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the button in DOM order.
Enter, SpaceActivates the button (browser default).

Focus

One shared ring: --focus-ring-width solid --color-focus-ring at --focus-ring-offset, shown on :focus-visible. The mocks removed the browser outline (outline: none) and relied on a border-colour change; the design system restores a visible ring.

Labelling

The visible label is the accessible name. A busy button is disabled, so Tab skips it. Requirement (not implemented in the mocks): announce the busy status in a live region.

Motion

Background and border colours transition over --duration-base. Nothing moves.

Touch

The default 2.5rem height exceeds the 24px WCAG 2.2 minimum. Small (2rem) buttons keep --space-3 or more from neighbours.

Content

  • Labels are short verbs or verb phrases: "Sign In", "Save", "Create account", "Delete".
  • Busy labels use the present participle with an ellipsis: "Signing in...".
  • Destructive buttons name the action ("Delete") and sit in a confirmation dialog beside "Cancel".
  • Primary goes last in a row; the safe action precedes it.

Drift

  • Primary background was #3D8A5A with a white label (4.2:1, fails 4.5:1); the system accent is #2D6B44.
  • Sign out was named .logout-btn; documented as .btn-sign-out.
  • Button type size differed between stylesheets (14px and 16px); the system uses --text-label.
  • The mocks removed the focus outline; the system adds the shared ring.
  • Busy state is only a disabled button with a changed label; no spinner is documented because none exists.
