Component · Identity

Logo mark

The co-op's mark: a rounded tile with three overlapping circles, drawn as inline SVG with token fills so it follows the theme. It sits beside the co-op's name at the top of the sidebar and above the sign-in form.

Overview

The logo mark says "this is the OWN Housing Co-op admin" at a glance. Use it in two places only: in the sidebar brand link, beside the co-op's name, and centred above the card on the sign-in style screens (sign in, register, forgot password). It always comes with the co-op's name in text nearby, so the mark itself is decoration and hidden from assistive technology.

It is drawn as inline SVG, not a picture file: three circles on a tile, filled with colour tokens. There is no bitmap logo. Do not use the mark as an avatar, an icon in a list or a button.

Anatomy

  1. Tile.logo-mark: a square filled with --color-accent. The wrapper rounds and clips its corners (--radius-lg, or --radius-md in the sidebar) and lifts it with --shadow-2.
  2. Top circleRadius 8 on a 48-unit grid, centred at 24, 17. Filled with --color-bg-surface.
  3. Left circleCentred at 17, 27. --color-accent-subtle-hover.
  4. Right circleCentred at 31, 27. --color-accent-subtle. Each circle has a 1.5-unit --color-accent outline, so the overlaps read in both themes.

Variants

One mark in two settings. The SVG is the same; the wrapper decides the size, corner and shadow.

Sizes

Two sizes, set by the wrapper. The SVG has a 48-unit view box and fills its tile, so it is sharp at any size and any zoom.

32px (--size-avatar-sm) in the sidebar · 64px (--size-avatar-xl) on sign-in screens

States

The mark itself is decoration and has no states. In the sidebar it sits inside the brand link, which has the link's hover and focus.

Responsive behaviour

  • The mark keeps its size at every width. Its sizes are in rem, so it grows with the browser's zoom along with the co-op's name beside it.
  • The sidebar shows from 768px. On phones the bottom tab bar has no brand, so the mark appears only on the sign-in screens there.
  • On sign-in screens it stays centred above the card from 320px up.

Theming

Every fill is a role token, so the mark follows the theme with no second file: a violet tile with pale circles in light, a light violet tile with deep circles in dark.

Accessibility

Role and pattern

Decorative. The wrapper has aria-hidden="true" and the SVG focusable="false", so a screen reader skips it. In the sidebar the link's text, "OWN Housing Co-op", is the link's name; on sign-in screens the co-op's name and the page heading are text beside it.

Keyboard

KeyAction
TabFocuses the sidebar brand link (first stop in the sidebar). The sign-in tile is never a stop.
EnterFollows the brand link to the Dashboard.

Focus

The brand link shows the shared 2px --color-focus-ring ring around the mark and the name together.

Labelling

Never give the SVG a <title> or an aria-label: the name is always in text beside it, and a label would be read twice.

The mark carries no information, so 1.4.11 does not require it; the pairs above show it still reads clearly in both themes. The co-op's name beside it meets 4.5:1.

Motion

None. The mark never animates.

Touch

The sidebar brand link is the full row, at least 44px tall with the name; the mark adds no separate target.

Content

  • Always pair the mark with the co-op's name in text: "OWN Housing Co-op".
  • Never put text, initials or a badge inside the tile.
  • Never redraw it in other colours, stretch it or add effects; change the role tokens if the theme changes.

Sources

Extracted from these admin mocks:

  • pages/admin-dashboard/default (the sidebar header, the same on every signed-in screen)
  • pages/admin-login/default (the 64px mark above sign-in)
  • pages/admin-landing/default (the mark in the landing page's top bar)

Drift from the implemented admin

  • The implemented mark has its own fixed palette: a terracotta tile with peach, amber and cream circles, written as colour literals in the SVG, and it never changes with a theme. The system draws the same shapes with --color-accent, --color-accent-subtle-hover, --color-accent-subtle and --color-bg-surface, outlines the circles, and follows light and dark.
  • The SVG rounds its own corners (rx="14"); the system draws a square and lets the .logo-mark wrapper round and clip it, so the corners and the shadow match at every size.
  • In the sidebar the mark is 28px inside a plain div.logo with the name in .logo-text, not a link. The system uses a .sidebar__brand link to the Dashboard with a 32px mark.
  • On sign-in (.header-icon) the mark is 64px with no tile shadow; the system adds --shadow-2 through .logo-mark.
  • Global: the implemented admin uses Outfit, Material Icons and a light theme only.
