Search bar

A single-line search field with a leading magnifier, used in the admin top bar.

WCAG 2.2 AAStatus: stableNative <input>

Overview

Use the search bar to filter the content of the current view, such as assets. It sits in the admin top bar. It filters as the person types; there is no submit button.

Anatomy

  1. ContainerBordered pill on --color-bg-surface, --radius-md, 1px --color-border-strong.
  2. Iconsearch glyph at 1.125rem in --color-fg-muted, aria-hidden.
  3. InputBorderless, transparent, fills the rest; placeholder "Search..."; aria-label="Search".

Variants

There is one search-bar look; the mocks' separate .search-input is a plain input documented as the form field.

Sizes

There is a single size: about 2.5rem tall, with the input filling the available width.

States

The focus ring is drawn around the whole container (:focus-within), not around the bare input.

The no-results state is shown by the list below the bar (empty state), not by the bar itself. A clear button is not implemented.

Responsive behaviour

The mocks define no @media rule for this component, so it does not change at the 640, 768 or 1024 breakpoints. The input has a fixed 200px base width in one stylesheet and flexes in the other; the system lets it fill its container with min-width: 0.

Theming

The product ships one light appearance, so this component has no theme variants. It reads semantic tokens only; see the tokens section.

Accessibility

Role and pattern

A text input labelled "Search". The WAI-ARIA Search landmark applies when the bar is wrapped in role="search"; the mocks do not do this, and the design system requires it on the surrounding container.

Keyboard

KeyAction
TabMoves focus into the input.
TypingFilters the list as the person types.
EscNot implemented; the field is not cleared.

Focus

The mocks removed the input outline (outline: none) without a replacement. The design system draws the shared focus ring around the container.

Labelling

No visible label; aria-label="Search" names the input. The placeholder is only a hint.

Content

  • Placeholder is "Search..." with an ellipsis, never an instruction.
  • The accessible name is "Search"; say what is searched when a page has several ("Search assets").

Drift

  • Mocks used a grey fill (#F5F4F1) for the container; the system uses --color-bg-surface with a strong border so the field boundary reaches 3:1.
  • The input outline was removed with no replacement; the container now takes the shared focus ring.
  • .search-input (border-colour focus) duplicated a normal input; folded into the form field.
