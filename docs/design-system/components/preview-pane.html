Preview pane

The public site in an iframe, in preview mode, rendering the draft and scrolled to the section being edited.

Overview

The preview pane is the right pane of the page editor: the public site itself, loaded in an iframe in preview mode so it renders the draft, scrolled to the section being edited. It uses the same short-lived preview link as "Preview site" in the publish bar; the public site shows a banner saying it is a preview. The office sees what a visitor would see after Publish, without publishing.

  • Use it in the page editor only.
  • Do not use it as a second editor: nothing inside the frame is editable, and the frame is reloaded after each save.

Anatomy

  1. Heading"Preview" with an eye icon; an h2 that labels the region.
  2. Open in a new tabThe same preview link, for a full window.
  3. NoteOne sentence: the frame shows the draft; visitors see the published website.
  4. FrameThe public site at ?preview={token}#section, 70vh tall at most 48rem, with a title.

Variants

One variant. For a website page the frame loads that page's address; for Home and Menu and footer it loads the home page.

Sizes

One size: the frame fills its pane, min(70vh, 48rem) tall.

States

Reloading after a save: the frame carries aria-busy="true" and keeps its last picture until the new one is ready. Expired link: the public site shows the published content with an "expired" banner, and the editor fetches a new link on the next save.

Both themes

The pane's chrome follows the admin theme; the public site inside follows its own light and dark setting.

Responsive behaviour

  • From 64rem the pane is the third column and sticks while the form scrolls. Below 64rem, and at 400% zoom, it is the Preview tab, full width, and the public site inside renders its own narrow layout.
  • The frame is never wider than its pane, so the editor never scrolls sideways.

Theming

Chrome only: --color-border-default and --shadow-1 around the frame, --color-fg-default and --color-fg-muted text.

Accessibility

Role and pattern

A <section> labelled by its heading, holding an iframe with a title. The frame's document is the public site, which meets WCAG 2.2 AA on its own and announces preview mode in a status banner.

Keyboard

KeyAction
TabOpen in a new tab, then into the frame's document and through the public page.
EnterOn the link, opens the preview in a new tab.

Focus

The shared ring on the link; inside the frame the public site's own 3px ring.

Labelling

The frame is titled "Preview of the public website with your draft". The link says it opens a new tab.

Contrast

Heading
Note

Motion

None in the pane; the frame scrolls to the section with the public site's smooth scroll, which it zeroes under reduced motion.

Touch

The link is a small 36px button with a wide label; the frame scrolls by touch.

Content

  • Heading "Preview"; link "Open in a new tab"; note "Shows your draft, scrolled to the section you are editing. Visitors see the published website."
  • Never "live preview", "WYSIWYG" or "render".
