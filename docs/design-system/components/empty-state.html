Empty state

The empty state tells people a list has nothing in it: an optional icon and one sentence, nothing more.

WCAG 2.2 AAStaticNo action

Overview

An empty state replaces a list or section that has nothing to show: no requests, no documents, no messages, and the no-results outcome of a search or filter. It is an icon above one sentence.

  • It fills the area where the list would have been.
  • There is no title and no action button in the mocks, so neither is part of the component.
  • Empty (nothing exists) and no-results (nothing matches) use the same component with different words.

Anatomy

  1. Icon (optional)3rem Material icon, centred, aria-hidden. Some mocks omit it.
  2. MessageOne sentence in --text-body, --color-fg-muted, centred.

Variants

One variant, with or without the icon. The mocks use an icon in the full-page lists and plain text inside cards (for example "No recent requests" on the dashboard).

inbox

No documents found

No recent requests

With icon (list pages) and without (inside a card).
HTML
<div class="empty-state">
  <span class="material-icons" aria-hidden="true">inbox</span>
  <p>No documents found</p>
</div>

<div class="empty-state"><p>No recent requests</p></div>

Sizes

One size. Padding is 48px by 20px; the mocks vary it from 24px to 48px by screen, resolved to the single value.

States

An empty state is static: it is shown while the collection is empty and removed once content arrives. It has no interactive states.

Responsive behaviour

No breakpoint rules apply; the block is centred and its text wraps. In grid lists (documents, assets) the mocks stretch it across every column; the layout, not the component, owns that.

Theming

The product ships one light appearance; there are no theme variants. It reads the muted foreground only.

Accessibility

Role and pattern

Plain text in a block; no role, no widget pattern. The icon is aria-hidden. The mocks do not announce the change from loading to empty; the design system requires the container that holds the list to be a polite live region (aria-live="polite") when results change by search or filter.

The sentence is the accessible content. Name what is empty ("No documents found"), not just "Empty".

Content

  • Say what is missing in plain words: "No documents found", "No recent requests".
  • For a search or filter with no matches, name the cause in the sentence rather than repeating the empty text.
  • One sentence, no calls to action (the mocks have none).

Drift

  • Mocks: padding differs by screen (24px, 40px, 48px by 20px) and the icon is 48px with a bottom margin of 8px or an SVG with a 12px margin. Resolved to 48px by 20px and a 3rem Material icon with 8px gap.
  • Mocks: text colour is a translucent black (about 80% alpha); resolved to --color-fg-muted.
  • Mocks: the dashboard "No recent requests" is a bare div with no paragraph; the system wraps the message in a paragraph.
