Checkbox

A native checkbox for a yes or no choice: the remember-me option on sign in and the privilege toggles in role management.

WCAG 2.2 AAStatus: stableNative <input type="checkbox">

Overview

Use a checkbox for an independent on or off choice. The product uses it in two places.

  • Labelled checkbox (.checkbox-label): a visible label beside the box, for "Remember me".
  • Privilege toggle (.privilege-toggle): a bare checkbox in a roles table cell, named by the column and row.

Anatomy

  1. BoxNative checkbox, 1.125rem square, tinted with --color-accent.
  2. Label--text-body-sm, beside the box with --space-2 gap; clicking it toggles the box.
  3. Accessible nameThe wrapping label, or an aria-label for a bare privilege toggle.

Variants

Left: labelled checkbox. Right: privilege toggle in a table cell.
HTML
<label class="checkbox-label"><input type="checkbox">Remember me</label>
<input class="privilege-toggle" type="checkbox" aria-label="Read privilege for Board member">

Sizes

There is a single size, 1.125rem square.

States

Native states; focus forced with data-state.

UncheckedCheckedFocusDisabled

An indeterminate state is not implemented.

Responsive behaviour

The mocks define no @media rule for this component, so it does not change at the 640, 768 or 1024 breakpoints. The label wraps naturally; the box stays 1.125rem.

Theming

The product ships one light appearance, so this component has no theme variants. It reads semantic tokens only; see the tokens section.

Accessibility

Role and pattern

Native <input type="checkbox">: the WAI-ARIA Checkbox pattern with built-in semantics.

Keyboard

KeyAction
TabMoves focus to the checkbox.
SpaceToggles the checked state.

Focus

One shared ring: --focus-ring-width solid --color-focus-ring at --focus-ring-offset, shown on :focus-visible. The mocks removed the browser outline (outline: none) and relied on a border-colour change; the design system restores a visible ring.

Labelling

Labelled checkboxes are wrapped in a label. Privilege toggles have no visible label; they need a specific aria-label naming role and privilege. The mocks use values like "privilege-read", which is a test id; the system requires "Read privilege for <role>".

Motion

None.

Touch

The 1.125rem box meets the 24px minimum only through its label; the labelled variant makes the whole row clickable. Privilege toggles sit in table cells with surrounding padding. Requirement: give toggles at least 24px of target.

Content

  • Labels are positive statements: "Remember me".
  • Bare toggles are named with their row and column: "Write privilege for Treasurer".
