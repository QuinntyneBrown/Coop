List item

A list item is one row in a vertical list. It leads with an avatar or an icon tile, then a title with a line of metadata, and may end with a badge or time. The selected item carries a 3px accent marker on its left edge.

Overview

The mocks have several row types that share one structure: the messaging .conversation-item, the profile switcher's .profile-card, the dashboard's .notice-item, and the asset and document rows that lead with a thumbnail or document icon. The design system consolidates them into .list-item.

  • Use a list item for rows that are compared at a glance or chosen from: conversations, profiles to switch to, notices, assets.
  • Use a table when rows have several comparable columns and row actions.
  • Use a card when each entry needs a title and a paragraph of its own.

Anatomy

  1. Row.list-item: flex row, 12px gap, 12px by 20px padding, hairline divider below.
  2. Leading visual (optional)An avatar for people and conversations, or an .icon-tile for documents and assets.
  3. Title.list-item-title: semibold --text-label.
  4. Meta.list-item-meta: caption size, muted; preview text, type, date or size.
  5. Trailing (optional)A badge (unread count) or a time.

3px --color-accent left border and --color-accent-subtle fill. Set with aria-current="true" (alias .selected).
  • The selected marker is a border added to the row, so unselected rows should reserve it (a 3px transparent left border) or the content of the selected row shifts 3px to the right. The mock had the same shift. See Drift.
  • Disabled and loading rows are not implemented. An empty list uses an empty state.

Responsive behaviour

  • The row is fluid. The text column shrinks and wraps; the trailing badge keeps its width.
  • On the messaging page, at max-width: 768px the conversation list becomes full width and hides when a chat is open (.conversation-list-panel.hidden-mobile), with a back button to return. That is page layout; the row itself does not change.
  • At max-width: 640px the documents list collapses to one column.

Theming

Icon tile tints use the semantic status tokens.

Accessibility

Role and pattern

The list is a semantic list (<ul>/<li>, or role="list"/"listitem" on divs) so the number of items is announced. The row's primary control is a native <a href> (or <button> when it changes the view in place) around the title. The mocks used div role="link" tabindex="0" with no key handler; the system requires a native control.

Keyboard

KeyAction
Tab / Shift+TabOne tab stop per row, on the title link.
EnterOpens the item.
SpaceActivates it when the control is a <button>.

Focus

The ring (2px --color-focus-ring) appears on the title link, offset 2px. Clicking anywhere on the row activates the link, but focus lives on the link.

Labelling

The link text is the item's title. Avatars and icon tiles are aria-hidden. An unread badge needs text a screen reader can read: "2 unread" (visually hidden suffix), not a bare "2". The selected row has aria-current="true", so the marker is not conveyed by colour alone.

Motion

Background changes over --duration-base (200 ms); nothing moves.

Touch

Rows are at least 62px tall (12px padding around a 36px or 48px visual), above the 44px comfortable target, and the whole row is clickable.

Content

  • The title is the item's name: a subject, document title or profile name. It truncates with an ellipsis rather than wrapping beyond one line.
  • Meta is the first useful detail: the last message, "Type · date", or "size · date". Separate parts with a middle dot.
  • Unread counts are numbers only; keep them to the badge.
  • Dates use one format on a page.

Drift

  • Conversation, profile and notice rows were three separately styled components with different paddings (12px or 14px by 20px), radii (10px) and selected tints (5% green). The system merges them into .list-item.
  • The selected marker was added only on selection, shifting the row's content 3px. The system should reserve a transparent 3px border on every row (proposed change to components.css).
  • Rows were div role="link" tabindex="0" with no Enter or Space handling.
  • Document type icons used 10% tints of raw colours; they now use the semantic status tokens (.icon-tile-success|info|warning).
  • The conversation divider was the canvas colour and the other rows used the card border colour; the system uses --color-border-default.
  • Asset size is shown as a raw number with no unit.
