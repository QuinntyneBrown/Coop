Site tree

The Website area's own navigation: the public site laid out the way a visitor meets it. Home, Pages with one entry per page and "Add a page", Menu and footer, Board of directors, Photos and Look.

Overview

The site tree is the Website area's own navigation: the public site laid out the way a visitor meets it. Home, then Pages with one entry per website page and "Add a page", then Menu and footer, Board of directors, Photos and Look. Choosing an item opens its editor; the current item is marked. It replaces four flat sidebar entries (Website, Pages, Board, Assets) with one sidebar entry and this tree inside it.

  • Use it on the Website landing (/website) as the main content, drawn as cards, and beside the Board of directors list as a column from 64rem.
  • Do not use it on the page editor: the editor needs the width for its three panes, and the breadcrumb "Website / Home" leads back to the tree.
  • Documents and notices stay under Community in the sidebar; the tree does not list them.

Anatomy

  1. ItemAn <a class="site-tree__link"> with a 20px stroke icon and a label; the current one carries aria-current="page" and the accent-subtle fill.
  2. Group.site-tree__group: "Pages" is a label, not a link; it names the nested list.
  3. Nested list.site-tree__list--nested: indented behind a hairline, one entry per page in menu order.
  4. Add item.site-tree__link--add in the accent colour with a plus icon: the way to create a page from where pages live.

Sizes

One size: 44px rows (--target-min) in the column, 48px (--target-comfortable) as cards.

Responsive behaviour

  • From 64rem .website-shell is a two-column grid: the tree in a 15rem column, the screen beside it. Below 64rem the tree stacks above the screen at full width; on the landing it is the content, so nothing stacks.
  • Labels wrap at 320px; nothing is cut off and the page never scrolls sideways.

Theming

Text tokens only: --color-fg-muted for items, --color-fg-default for the group label and hovered items, --color-accent-subtle and --color-fg-accent for the current item and "Add a page", --color-border-default for the nested rule. Each is defined in both themes.

Accessibility

Role and pattern

A <nav aria-label="Website"> landmark holding nested lists of links, as the sidebar does. It is a plain navigation list, not an ARIA tree: there is no expand or collapse, so no tree keyboard model is needed. The current item carries aria-current="page".

Keyboard

KeyAction
Tab / Shift+TabMoves through the links in reading order; the "Pages" group label is not a stop.
EnterOpens the editor for the item.

Focus

The shared 2px --color-focus-ring with a 2px offset around the whole row.

Labelling

The landmark is "Website", distinct from the sidebar's "Admin sections" and the breadcrumb. Page entries use the page's own title. Icons are aria-hidden.

Contrast

Item on surface
Current item
Add a page
Focus ring on surface

Motion

Background and colour fade over --duration-fast; none under reduced motion.

Touch

Every row is at least 44px tall and full width, 48px as cards, for the older people who run the office.

Content

  • Plain words in sentence case: "Home", "Pages", "Menu and footer", "Board of directors", "Photos", "Look". Never "CMS", "hero", "slug", "assets" or "theme".
  • Page entries are the page titles as visitors see them in the menu, in menu order.
  • "Add a page" is a verb phrase and the last entry of Pages.
