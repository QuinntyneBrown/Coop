Block card

A page body block summarised: its kind (Heading, Paragraph, Bullet list, Photo, Link button, Existing content) and the first line of its text.

Overview

A website page is made of body blocks: Heading, Paragraph, Bullet list, Photo, Link button, and for pages written before blocks existed, one Existing content block holding the old HTML. In the page editor each block is a section in the section list; the block card is how a block is shown wherever it is summarised rather than edited, for example in the site tree's page preview or a future page overview: its kind in small capitals and the first line of its text.

  • Use it to summarise a block outside its form.
  • Do not use it as the editor; the form in the Edit pane is.

Anatomy

  1. KindAn overline with the block's icon: Heading, Paragraph, Bullet list, Photo, Link button, Existing content.
  2. PreviewThe first two lines of the block's text, clamped.

One card per kind; only the icon and the text differ.

Responsive behaviour

  • Cards fill their container and stack at 320px; the preview clamps to two lines so a long paragraph never pushes the layout.

Theming

The card's tokens; the kind in --color-fg-muted.

Accessibility

Role and pattern

An article with text. The kind is visible text, not colour or icon alone.

Keyboard

Not focusable unless it is a link.

Focus

None.

Labelling

The icon is decorative; the kind word carries the meaning.

Contrast

Kind on surface

Motion

None.

Touch

Not a target.

Content

  • Kinds in sentence case: "Heading", "Paragraph", "Bullet list", "Photo", "Link button", "Existing content". Never "H2", "rich text", "image", "CTA" or "HTML block".
  • The preview is the block's own words; a photo shows its description, a link shows its label and address.
