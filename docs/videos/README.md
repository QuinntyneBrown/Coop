# Videos

Narrated videos made from a script, a slide deck and captions. See the
`creating-videos` skill in `.claude/skills/` for the workflow. Tools live in
`tools/video-audio/` and `tools/video-build/`. Media files go through Git LFS
(see `.gitattributes`); `.cache/` folders are never committed.
