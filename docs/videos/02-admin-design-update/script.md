# 02 · The admin desk, on the Shelfie design

## Welcome

Hello again. This is a short update for the board.

[pause 2s]

The admin desk, where your office looks after the website, requests, documents and members, has a new look. Every screen you are about to see is the real admin desk, running today. It is not a drawing.

[pause 2s]

## The new look

First, the dashboard. The colour is now a soft violet, in place of the old green. The words are set in the rounded type that your own computer already has, so the text looks the same on every machine.

[pause 2s]

The menu on the left is easier to scan. Each section has a simple outline icon, and the section you are in is highlighted.

[pause 2s]

Buttons are rounder and bigger, and every one of them is a comfortable target to click or tap. The tags that show a request as new, received, started or completed keep their words, so colour is never the only clue.

[pause 2s]

## Light or dark

Next, light and dark. The admin desk now follows the setting on your device. If the office works in the evening, and a dark screen is easier on the eyes, the whole desk turns dark by itself. The contrast stays strong in both.

[pause 2s]

## Windows and forms

Then, windows. When you add a user, a window opens in front of the page. It is a proper dialog, so the keyboard stays inside it, the escape key closes it, and focus returns to where you were. Labels sit above every box, and the buttons say plainly what they do.

[pause 2s]

## On a phone

The new design starts from the small screen. On a phone, everything stacks into one column, and nothing runs off the edge. That still holds at four hundred percent zoom.

[pause 2s]

## What did not change

Now, what did not change. The words on the screens, and the way each task works, are the same as before. Nobody needs to learn anything new. The design system lives in one place in the repository, and the admin desk loads it from there, so the look stays consistent from screen to screen.

[pause 2s]

Some improvements are still to come, such as a more menu on phones, clearer error messages and friendlier empty pages. Each one will be designed first, and then built.

[pause 2s]

## Thank you

Thank you for watching.

[pause 3s]
