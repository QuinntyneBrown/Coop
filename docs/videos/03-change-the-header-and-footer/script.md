# 03 · Change the header and footer

## Welcome

Hello. This video is for the co-op office. It shows how to change the header and the footer of the public website.

[pause 1s]

The header is the strip across the top of every page, with the co-op's name, the menu and the sign-in button. The footer is the dark band at the bottom, with the contact details and more links. Change them once, and every page follows.

[pause 2s]

## Open the header

Sign in to the office app, and select Website in the menu on the left. At the top, under On every page, you see two cards. Header, and Footer.

[pause 1s]

Select Edit on the Header card. The Edit Header form opens.

[pause 2s]

## The name

The first box is the Site name. It shows at the top left of every page, beside the logo. This one must be filled in.

[pause 1s]

Below it is the subtitle, which shows under the name on tablets and wide screens. It is optional. Leave it empty, and nothing shows.

[pause 2s]

## The menu links

Next come the Menu links. These are the words across the top of the page, such as Home, About us and Contact.

[pause 1s]

Each menu link has two boxes. The Label is the word visitors see. The Address is where the link goes.

[pause 2s]

To change the order, use Move up and Move down. The first link shows first. To take a link away, select Remove.

[pause 1s]

To add a link, scroll to the end of the list and select Add menu link. A new, empty link appears, ready for a label and an address.

[pause 2s]

## Addresses

The Address box accepts four kinds of address.

[pause 1s]

A part of this website starts with a slash. For example, slash, hash, visit, goes to Visit or apply on the home page.

[pause 1s]

Another website starts with h t t p s, colon, slash, slash.

[pause 1s]

An email address starts with mailto, then a colon. And a phone number starts with tel, then a colon.

[pause 1s]

If the address is not one of these, the form shows a red message and does not save. That keeps visitors away from broken or unsafe links.

[pause 2s]

## The buttons

Below the menu links are two buttons. The Sign-in button sits at the top right, and takes members to their own sign-in page. Change its label if you prefer other words.

[pause 1s]

The Visit button shows only in the phone menu. On a phone, visitors select Menu and see the links, then the sign-in button, then this big Visit button at the bottom.

[pause 1s]

When everything looks right, select Save changes. A green message says, your changes are now on the website.

[pause 2s]

## The footer

Now the footer. On the Website page, select Edit on the Footer card.

[pause 1s]

The footer has three columns. On the left, the contact details. In the middle, links around the site. On the right, links for members.

[pause 2s]

The contact column starts with a heading, then the organisation name, the neighbourhood, the phone number and the email address. Type the phone number and email just as people should read them. The website turns them into links for you, so visitors can tap to call or write.

[pause 2s]

The middle column has its own heading and a list of Site links. The right column has a heading and a list of Member links. They work exactly like the menu links. Move them up or down, remove them, or add new ones.

[pause 2s]

At the very bottom are two lines of small print. The copyright line, and the website line. Change them like any other text.

[pause 1s]

Almost everything in the footer is optional. Leave a box empty, and that line simply does not show. Remove every link from a list, and that column goes away.

[pause 1s]

Select Save changes, and the footer changes on every page at once.

[pause 2s]

## In short

So, in short. Select Website. Edit the Header for the name, the menu and the buttons. Edit the Footer for the contact details, the links and the small print. Check each address, then save.

[pause 1s]
