# 05 · Add pages and update the board

## Welcome

Hello. This is the last video in the series about the public website. It shows two more things the office can change. The extra pages in the website menu, and the board of directors on the home page.

[pause 2s]

## Your pages

Besides the home page, the website can have pages of its own, such as About us, or How to apply. Each one appears in the menu at the top of every page, after the menu links from the header.

[pause 1s]

Select Pages in the menu on the left. You see every page, with its web address. The address is made from the title, so How to apply lives at slash pages, slash how to apply.

[pause 1s]

Each page also says whether it has a hero photo. Select Open on the website to see the page just as visitors do.

[pause 2s]

## Add a page

To add a page, select New page. A form opens.

[pause 1s]

First, give the page a title. Two pages cannot share the same title.

[pause 1s]

If you like, add a hero photo, a big photo under the title. Select Choose photo. The same Choose a photo window opens as on the Website page. Pick a photo from the library or upload a new one. Then describe it for people who cannot see it.

[pause 2s]

Then write the page text. Plain words work well. If you want a heading or a list, the form shows the few simple tags you can use.

[pause 1s]

Select Save page. A green message says the page is now on the website, and it appears in the website menu straight away.

[pause 2s]

## Change or remove a page

To change a page, select Edit beside it. The form opens with the page filled in. Here you can also choose a different photo, or select Remove photo. Make your changes, and select Save page.

[pause 2s]

To take a page away, select Remove. A box asks you to be sure, and reminds you that the page leaves the website menu straight away. Select Remove page, or Cancel to keep it.

[pause 2s]

## The board

Now the board. On the home page, Meet the board shows each director with a portrait, a name and a role.

[pause 1s]

Select Board in the menu on the left. Here you see every director, in the order the website shows them.

[pause 2s]

To add someone, select Add director. Type their name, and their role on the board, such as President, Treasurer, Secretary or Member at large.

[pause 1s]

The photo address is optional. If you have the web address of a portrait, paste it here. Without one, the website shows the director's initials instead.

[pause 1s]

Select Save director. A green message says they are now on the board list, and they join the end of the list on the home page.

[pause 2s]

## Order and changes

To change the order, use Move up and Move down. The first director shows first on the home page.

[pause 1s]

To change someone's role after an election, select Edit beside their name, make the change, and select Save director.

[pause 1s]

When someone leaves the board, select Remove. A box asks you to be sure. Select Remove director, and they leave the home page straight away. You can add them again later.

[pause 2s]

## In short

So, in short. For your own pages, select Pages. Use New page to add one, Edit to change it, and Remove to take it away. For the board, select Board. Add, edit, move or remove a director.

[pause 1s]

Together with the Website page, that is everything visitors see on the public site. Take your time, check the website after each change, and ask if anything is unclear. Thank you for watching.

[pause 3s]
