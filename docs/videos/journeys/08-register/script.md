# 08 · Register

## Welcome

Hello. This short video shows how to create your member account.

[pause 2s]

The office sends you an invitation code. It is a code that says you belong. Keep it close by before you begin.

[pause 2s]

## Create your account

Start on the co-op's website, and tap Member sign in. Under the Sign in button, tap Create an account.

[pause 2s]

The page says Create your account. You will see four boxes to fill in.

[pause 1s]

First, type your Invitation code. Then choose a username. This is the name you will sign in with.

[pause 2s]

Next, choose a password, and type it again in Confirm password. Then tick the box that says I agree to the terms and conditions.

[pause 2s]

When you are ready, tap Create account. While it works, the button is greyed out, so you cannot tap it twice.

[pause 2s]

## If something is missing

If something is missing, a box at the top says how many things to fix, and a short note appears under each one. If the two passwords are not the same, it says, These don't match. Type the same password in both boxes. Fix each one, and try again.

[pause 2s]

If the code is not right, a message says We couldn't create your account. Check your invitation code, then try again. If it still does not work, call the office, and they will help.

[pause 2s]

## In short

So, in short. Have your code ready. Fill in the four boxes, tick the box, and tap Create account. Next, you will set up your profile.

[pause 1s]

Thank you for watching.

[pause 3s]
