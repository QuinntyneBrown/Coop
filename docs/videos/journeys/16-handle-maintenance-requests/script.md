# 16 · Handle maintenance requests

## Welcome

Hello. This short video is for the co-op office. It shows how to look after the repair requests that members send.

[pause 2s]

Each request moves along four steps. New, Received, Started and Completed. The member can see each step, so she always knows where things are.

[pause 2s]

## Find a request

Choose Maintenance in the menu on the left. The page lists all requests, each with its step.

[pause 2s]

Above the list are tabs. All, New, Received, Started and Completed. Choose New to see only the requests that nobody has looked at yet.

[pause 2s]

Choose a request to open it. You see who sent it, when, how urgent it is, and what is wrong, with the address and a phone number.

[pause 2s]

If the member added photos, they show under Photos.

[pause 2s]

## Move it along

On a new request, choose Receive Request. This tells the member someone is on it.

[pause 2s]

When work begins, choose Start work. The request now shows as Started.

[pause 2s]

When the job is done, choose Finish work. The request shows as Completed, and there is no next step.

[pause 2s]

## Comments

To leave a note, choose the Comments tab. Type in the box, and choose Send. The comment shows with a name and the time.

[pause 2s]

## In short

So, in short. Filter the list. Open a request. Receive it, start it, finish it, and leave a comment when it helps.

[pause 1s]

Thank you for watching.

[pause 3s]
