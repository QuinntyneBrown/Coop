# 14 · Use the phone menu

## Welcome

Hello. This short video shows how to find your way around the co-op website on a phone.

[pause 2s]

A phone screen is small. So the website tucks its links away behind one button, to keep the page easy to read.

[pause 2s]

## Open the menu

At the top right of the page, you see a button that says Menu. Tap it.

[pause 2s]

A list opens. Home, About us, Living here, What's on, Contact, and How to apply.

[pause 2s]

Below the list are two larger buttons. Member sign in, for members. And Book a visit, if you would like to come and see us.

[pause 2s]

Tap any link to go there.

[pause 1s]

## Close the menu

While the list is open, the button at the top says Close. Tap Close, and the list tucks away again.

[pause 2s]

If you use a keyboard, the Escape key closes it too.

[pause 2s]

## In short

So, in short. Tap Menu to see the links. Tap a link to go there. Tap Close to put them away.

[pause 1s]

Thank you for watching.

[pause 3s]
