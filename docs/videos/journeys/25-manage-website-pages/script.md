# 25 · Manage website pages

## Welcome

Hello. This short video shows how office staff add, change and remove pages on the public website.

[pause 2s]

Each page appears in the website menu, and it is live straight away.

[pause 2s]

## Your pages

Select Pages in the menu on the left. You see every page, such as About us and How to apply, with its address.

[pause 1s]

Open on the website shows the page as visitors see it.

[pause 2s]

## Add a page

To add one, select New page. A form opens.

[pause 1s]

Give the page a title. If you like, paste the address of a photo from the Assets library, and describe the photo for people who cannot see it.

[pause 1s]

Then write the page text. Plain words work. Select Save page, and the new page shows on the list.

[pause 2s]

## Change or remove a page

To change a page, select Edit beside it. The form opens with the page filled in. Make your changes and select Save page.

[pause 2s]

To take a page away, select Remove. A box asks you to be sure. Select Remove page, or Cancel to keep it.

[pause 2s]

## In short

So, in short. Select Pages. Use New page to add, Edit to change, and Remove to take a page away.

[pause 1s]

Thank you for watching.

[pause 3s]
