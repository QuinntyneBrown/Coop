# 27 · Manage profiles

## Welcome

Hello. This short video is for the co-op office. It shows how to look after the profiles on an account.

[pause 2s]

One person can have more than one profile. For example, a member profile and a board member profile.

[pause 2s]

## Edit a profile

Start with Profiles, in the menu on the left. Under My Profiles, you see each profile, with its name and its kind. The one in use is marked Active.

[pause 2s]

Select a profile, and a form opens beside the list. You can change the first name, the last name and the phone number. Change Avatar sets a new picture.

[pause 2s]

When you are done, choose Save Changes. Or choose Cancel to leave it as it was.

[pause 2s]

## Set a board title

A board member profile has one more box, Board Title. Type the title here, such as Treasurer, and choose Save Changes. A green note says Profile updated successfully.

[pause 2s]

## In short

So, in short. Open Profiles. Select a profile. Make your change, and save. That is all.

[pause 1s]

Thank you for watching.
