# 24 · Manage website pages

## Welcome

Hello. This short video shows how office staff add, change and remove pages on the public website.

[pause 2s]

Pages such as About us and How to apply answer visitors' questions. Each one is a banner at the top, then the blocks that make up its body.

[pause 2s]

## Your pages

Select Website in the menu on the left. Under Pages you see every page, such as About us, How to apply and Our garden.

[pause 1s]

Select a page to open it, or select Add a page to start a new one.

[pause 2s]

## Add a page

The new page starts with its Page banner. Give the page a title. The page address comes from the title.

[pause 1s]

If you like, select Choose photo, and describe the photo for people who cannot see it.

[pause 1s]

Show this page in the website menu is ticked. Untick it to write the page before visitors can see it. Then select Create page.

[pause 2s]

A page that is not in the menu yet says so at the top. Visitors cannot open it until you tick the box again.

[pause 2s]

## Build the body

Under Add to the page, choose a Heading, a Paragraph, a Bullet list, a Photo or a Link button. Each one joins the list of sections.

[pause 1s]

Choose a section to fill it in. Move up and Move down change the order, and Remove takes a block away. Then select Save page.

[pause 2s]

## Remove a page

To take a page away, open it and select Remove page. A box asks you to be sure. Select Remove page, or Cancel to keep it.

[pause 2s]

## Publish

Your pages go into the same draft as the rest of the website. When you are ready, select Publish, then Publish again in the box, and visitors see your pages.

[pause 2s]

## In short

So, in short. Select Website. Use Add a page to start, add blocks to the body, save the page, and publish.

[pause 1s]

Thank you for watching.
