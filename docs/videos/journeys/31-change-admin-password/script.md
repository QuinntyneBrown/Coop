# 31 · Change admin password

## Welcome

Hello. This short video is for the co-op office. It shows how to change the password for the office account.

[pause 2s]

A good password keeps members' details safe. Change it if you think someone else may know it.

[pause 2s]

## Change the password

Start on the Change Password page. You can reach it from your profile, with the Change Password button.

[pause 2s]

Type your current password first. Then type a new one in New Password. It must be at least eight characters long.

[pause 2s]

Type the new password once more in Confirm New Password. This makes sure there is no typing mistake.

[pause 2s]

Then choose Update Password.

[pause 2s]

## If something is wrong

If the two new passwords are not the same, the page says, passwords do not match. Type them again, carefully.

[pause 2s]

If the current password is wrong, the page says so too, and nothing changes. To leave without changing anything, choose Cancel.

[pause 2s]

## In short

So, in short. Current password. New password, twice. Update Password. That is all.

[pause 1s]

Thank you for watching.
